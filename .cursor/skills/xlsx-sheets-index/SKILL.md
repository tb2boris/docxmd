# Оглавление книги XLSX

Один проход по уже собранным файлам docxmd. Исходный `.xlsx` не открывать для правки и не перезаписывать.

## Откуда читать

Для книги `реестр.xlsx` конвертер кладёт рядом:

- `реестр.md` — оглавление: лист, размер, строка заголовков, превью первых 30 строк, ссылка на CSV. Если строк больше, полные данные только в CSV.
- `реестр/<Лист>.csv` — значения ячеек, UTF-8 с BOM. Один видимый лист — один файл.
- `реестр.sheets.json` — порядок листов, скрытые листы (только имя и пометка, без ячеек), объединения, адрес и текст формулы, признак `cached: false`, если посчитанного значения в файле нет.

Сначала читать `.md`. Точные ячейки брать из CSV. Формулу и объединения брать из `sheets.json`.

## Как понимать ячейки

- В CSV записано посчитанное значение. Дата и время — ISO. Целое число без хвоста `.0`.
- Пустая ячейка при формуле с `cached: false` — значения в файле нет. Ноль вместо пустоты не подставлять.
- Повтор значения по объединённому диапазону в CSV — это копия левой верхней ячейки. Сам диапазон смотреть в `merges`.
- Скрытый лист в CSV отсутствует. В оглавлении одна строка: лист скрыт и пропущен.
- Имена листов и имена файлов — как в книге, даже если рядом включена деперсонализация.

## Чего не делать

- Не править исходный XLSX.
- Не восстанавливать сводные таблицы, диаграммы, картинки и примечания: эта выгрузка их не содержит.
- Не вызывать конвертер повторно, если `.md`, CSV и `sheets.json` уже лежат рядом и вопрос можно закрыть по ним.
